# Legacy Factorio graphical prototype

This optional macOS prototype uses screenshots and bounded keyboard/mouse input for one foreground Factorio client. It requires a graphical session, screen-recording/accessibility permission and configured inference limits. It does not establish ten-worker coordination or live acceptance.

The current swarm uses a headless server, scripted actors and a separate graphical viewer. Use [the Factorio runtime guide](../../factorio/README.md) and [prompted worker guide](../../docs/factorio-inference.md) for that path. Do not confuse prototype traces with engine receipts or verified production.
