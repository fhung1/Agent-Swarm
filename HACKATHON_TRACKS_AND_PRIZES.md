## Project Track Plan

These are proposed targets based on the project ideas discussed so far. The VM fleet manager is supporting infrastructure for the game-agent swarm, rather than a separate user-facing project.

### Agent Swarm: collaborative paper-trading agents

The project combines specialized research agents, evidence-linked debate, a deterministic risk gate, paper execution, and a live shared dashboard.

**Best-fit targets:**

- **FinTech:** Agents research companies and make auditable paper-trade or no-trade recommendations.
- **Actually Intelligent (AI):** Agents divide research, challenge one another, and take a bounded action through the paper-trading workflow.
- **Best Use of Spacetime:** SpacetimeDB is the real-time coordination and audit layer for shared tasks, messages, proposals, risk decisions, and paper-order state.
- **Best Design:** A clear portfolio and decision-trace dashboard can make the agent workflow easy to understand and review.

**Extensions that could add tracks:**

| Extension | Additional track | Effort | Fit and scope |
| --- | --- | --- | --- |
| Add a conversational coordinator registered on Agentverse and discoverable through ASI:One. Let a user request an analysis, then return the completed paper-trade decision and trace. | ASI:One Agent Challenge | High | Strong fit if the end-to-end registration, discovery, meaningful action, and required ASI submission are completed. Keep execution paper-only. |
| Add an iMessage front end through Photon's Spectrum. A user can ask for a company review, receive progress updates, and approve a paper proposal. | Agents in iMessage using Photon | Medium–high | Strong natural interface for the existing coordinator. Spectrum must connect the agent to iMessage. |
| Add a Neon-backed archive for filings, evidence artifacts, and run analytics, while SpacetimeDB continues to serve live coordination. | Best Use of Neon Backend | Medium | Viable if Neon has a substantial job in the product and the dashboard demonstrates it. Avoid a superficial second database. |
| Add a spending and savings view using Nessie's mock accounts, merchants, bills, and transactions alongside portfolio decisions. | The Best Use of Nessie | Medium–high | A credible financial-wellness extension, but it broadens the product beyond investment research. Build only if the team wants a personal-finance angle. |
| Deliver an interactive spoken portfolio briefing, with cited reasons for a trade or abstention and follow-up voice questions. | Best Project Built with ElevenLabs | Medium | Better fit when voice supports a real review workflow than when it only reads a static summary. |
| Use Notability Pro for ideation, debate summaries, or wireframes; capture at least two screenshots and include the required submission note and tag. | Trust the Process (Notability) | Low | Low engineering cost, but the team must actually use Pro during the event and preserve the evidence. |
| Design the operator dashboard and shared decision flow in Figma, then polish the interaction and visual hierarchy. | Best Design | Low–medium | Improves the core submission as well as the design-track entry. |

**Recommended scope:** prioritize the three best-fit tracks above; treat Best Design as a quality bar. The most coherent extension choices are Notability and one product-facing integration (ASI:One or Photon). Add Neon or Nessie only if the integration can be demonstrated end to end.

### Vision-only game-agent swarm

Ten agents each control an isolated graphical game client. Agents receive their own screenshots, act through mouse and keyboard, and coordinate without server-side world telemetry.

**Best-fit targets:**

- **Actually Intelligent (AI):** Demonstrate multiple agents that perceive, plan, act, recover, and coordinate through the game UI.
- **Best Use of Spacetime:** Use SpacetimeDB for live task assignment, agent messages, run status, and an auditable action feed.
- **Best Design:** Build a polished control room showing the ten clients, each agent's current task, and recent visible actions.

**Extensions that could add tracks:**

| Extension | Additional track | Effort | Fit and scope |
| --- | --- | --- | --- |
| In a Factorio scenario, ask the swarm to meet a production goal while reducing visible power use, pollution, or resource waste; compare its result with a baseline. | Sustainability | Medium | A coherent game-based sustainability challenge if the metric is visible, measurable, and central to the demo. |
| Put a physical run/pause control and agent-status display on a hardware kit or microcontroller. | Beyond the Code (Hardware); possibly Best Use of FREE-WILi | Medium–high | Makes the operator control room tangible. FREE-WILi eligibility depends on using its kit meaningfully; confirm the kit's capabilities first. |
| Let a user assign a task and receive progress through Relay, including text, voice, or video interaction as supported by the app. | Interactive Agents (Relay) | High | Strong fit if the agent actually works inside Relay and the integration is part of the live demo. |
| Connect the coordinator to iMessage through Photon Spectrum for task requests and agent updates. | Agents in iMessage using Photon | Medium–high | A separate messaging integration from Relay; choose one first rather than building two front ends at once. |
| Give the mission-control agent a useful voice: accept spoken goals and provide expressive, context-aware progress reports. | Best Project Built with ElevenLabs | Medium | Can make the swarm easier to direct and observe; demonstrate it as an interaction loop. |
| Give the swarm a real-space mission-control theme using public mission data, Cursor, and Grok Imagine or Voice. | Make it Legendary | High | Requires a meaningful space-data-to-project connection and both required tools; a space-themed reskin alone is weak. |
| Use Notability Pro to plan roles, sketch the control room, or summarize team decisions; include the required screenshots and submission note. | Trust the Process (Notability) | Low | Easy to support during the hackathon if the team uses Pro and records evidence. |

**Recommended scope:** target AI and Spacetime first. Sustainability is the most natural thematic extension for a Factorio run; a physical control panel is the most natural route toward Hardware. Choose at most one messaging surface (Relay or Photon) and add voice only if it improves the agent interaction.

### Shared opportunities

- **Grand prize:** both projects can compete for it through a complete, understandable, working demo; it is an overall prize, not a separate integration track.
- **Useless AI / Dumbest Idea:** either project can add an intentionally silly mode, such as an agent that confidently optimizes the wrong objective or a factory swarm competing to build the least useful machine. Keep this as a small side quest.
- **Judged by an LLM:** create a self-contained judging task using the event's approved prize list and follow the submission instructions. Do not assume an LLM-generated result replaces any required project submission.
- **FinchNode and Presage:** would require a real healthcare or human-sensing use case. Neither current project has one; a healthcare pivot would be substantial and should be chosen only if the team wants that problem area.
- **Solana:** could support a tokenized game economy or prediction-market experiment, but it adds financial and smart-contract scope without helping the current core demo. Consider it only if on-chain behavior is central to the project.
