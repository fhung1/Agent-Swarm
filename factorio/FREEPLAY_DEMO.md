# Five-player freeplay demo

The current empty-inventory run uses five `gpt-6-astra` low-effort game actors and one `gpt-6-astra` high-effort orchestrator. The orchestrator has no game character or game-action interface: it reads the Factorio message board and directs actors with durable chat messages and run-scoped subtasks. The shared goal is to beat Factorio by launching a rocket. Actors can create and claim subtasks and request resources through a shared chest; request completion requires a matching deposit receipt.

The original ten-actor save is preserved at `.game-runs/freeplay-astra-start-1-ten-agent-checkpoint`; the earlier progressed checkpoint `.game-runs/freeplay-astra-1` is also preserved. The private local launcher loads the existing API-key profile in memory and is not tracked. The current run ID is `freeplay-astra-orchestrated-2`, with a 200-call limit per actor, 120 coordinator calls, and a one-hour deadline.
